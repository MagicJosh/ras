Every data part, on one page

Stat tiles, tables, charts and a heatmap, built from parts.css, chart.js and data.js. Every value, name and limit here is made up with CrispChart.rng. Point at a chart, or Tab to it and use the arrow keys, to read its values.

Stat tiles

A few headline numbers, each against its limits. A state shows as a color, an icon and a word; a tile without limits makes no verdict; a missing reading says "no data", never 0. All values are made up.

Charts on a panel grid

Panels on 12 columns that widen on a tablet and stack on a phone. Each panel header names the chart, its unit, the example tag and the source. All values, names and limits are made up.

Data table

Units in the headers, numbers right-aligned with fixed decimals per column, a state chip, an in-cell meter with its limits, a sparkline, group rows, a highlighted row and a total. Click or press Enter on a header to sort; on a phone the table scrolls sideways inside its box while the host column stays. All values are made up.

Spec table

The fixed facts about one thing, as key and value. Something not checked says so. All values are made up.

Heatmap

One value per cell on a one-hue scale with a legend. Every cell prints its value, so the color only helps the eye find highs and lows; the outlined cell is the highest. All values are made up.
